Update Hermes Dashboard

Pick the update path that matches how you installed the dashboard. After files update, restart the dashboard process and use Reload Dashboard to clear browser cache.

Dashboard helper

Use this screen from the gear menu when you forget the steps. You can run a guarded auto-update, or use the copyable manual paths below when you want full control.

Checks for a clean git checkout, fetches origin, pulls with --ff-only, and installs requirements. It refuses to overwrite local changes.

GitHub Desktop or another Git GUI

  1. Open the hermesdashboard repository in your Git app.
  2. Fetch origin, pull the latest main, then restart the dashboard launcher/service.
  3. Return here and click Reload Dashboard.

Download ZIP from GitHub

  1. Open the GitHub repository and choose Code → Download ZIP.
  2. Extract it over your dashboard install directory, preserving your local .env.local and launcher scripts.
  3. Restart the dashboard, then reload this page.

Terminal update

If you are comfortable with a shell, run this from the install directory:

git pull --ff-only && python -m pip install -r requirements.txt

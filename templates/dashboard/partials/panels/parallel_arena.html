Launch several strategies against the same task, compare lane artifacts, and synthesize a winner.

2026 orchestration notes baked into this MVP

  • Code-owned orchestration: parallel lanes are explicit, bounded, cancellable units; LLM routing can be layered in later.
  • Structured run records: every lane has status, timestamps, score fields, artifacts, and safety notes.
  • Trace-ready: run and lane IDs are stable so future OpenAI Agents/LangGraph traces can attach spans and artifacts.
  • Human control: cancellation is a first-class action; synthesis waits for completed/cancelled lanes.
